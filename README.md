# Biệt thự Tam Quan · La Rotonda B

A static site with three board sets:

- **La Rotonda B** (RB0–RB7, plus RB4b), taken unchanged from the
  [design canvas](https://claude.ai/code/artifact/7f50b71b-e25f-4a45-9de9-66d8f274766d).
- **Dinh thự Tam Quan** (DT0–DT8): a new design for the villa as an 18th-century French–Italian
  neoclassical mansion: rusticated base, giant Corinthian order, La Rotonda round hall with two curved stairs under a domed lantern,
  Grand Salon over a grotto pool. Concept, site plan, three plan boards, two elevations, a long section, and DT8 on joining
  the old house into one building (link block, a 29 m enfilade, one roof line at +15.00).
  Not on the canvas yet.
- **Mở rộng tạm** (U0–U2): a single-storey temporary extension for about five years, a U of light steel
  wings around the new lot that opens onto the old house's front yard; the road wing can stay as the
  mansion's garage and gatehouse.

It is plain HTML and CSS with no dependencies, so any static host works, including GitHub Pages.

- `index.html`: gallery of all boards, one section per set
- `view.html#<slug>`: one board at a time, either fitted to the screen or at 1:1. Use the
  arrow buttons or the ← → keys to page through the set.
- `boards/<slug>.html`: each board on its own, exactly as drawn (1480 × 1060 px; RB0 is 1000 × 1060)

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000. Opening `index.html` directly from disk also works.

## How it is built

Each folder `design/<set>/` holds one set: its `.dc.html` artboards and a `manifest.json` giving the order,
codes and titles. `design/site.json` holds the gallery header. `tools/build.py` unwraps each artboard into a
plain HTML page without changing its markup or SVG, then regenerates `boards/`, `assets/boards.js`
and `index.html`:

```bash
python3 tools/build.py
```

`design/rotonda-b/` holds the canvas originals. The DT boards in `design/dinh-thu/` are generated by
`design/dinh-thu/generate.py`, and the U boards by `design/mo-rong-tam/generate.py`. Their drawings are schematic and use the RB plan dimensions. To change an
idea, edit the script, then run it before the build:

```bash
python3 design/dinh-thu/generate.py
```

The generated files are committed, so the site runs without a build step. Do not edit them by hand.
Edit the sources and run the build again. `view.html`, `assets/site.css` and `assets/viewer.js`
are written by hand.

To add another set from the canvas (for example CHỐT or the MT facade studies), put its
`.dc.html` files and a `manifest.json` (with an `order`) in a new `design/<set>/` folder. The converter only accepts
static artboards. It stops with an error if an artboard uses template holes, `sc-*` / `dc-import`
elements or uploaded `/_blob/` assets.
